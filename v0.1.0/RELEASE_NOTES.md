## 小小你 v0.1.0 · 首个版本

孕期管理 Android App（中文界面），Kotlin + Jetpack Compose + Material 3，适配 OPPO Find N5 折叠屏内外屏。

### 功能
- **首页**：孕周 / 预产期 / 宝宝大小，首次启动填写末次月经或预产期（支持拍 B 超单 AI 推算）
- **产检记录**：增删改查；AI 识别产检单（日期、医院、孕周、体征、血常规 / B 超等指标、医生建议、下次产检日期）；下次产检本地通知提醒；体重曲线；产检时间表参考
- **孕期日记**：心情、标签、文字、照片，月历视图；AI 看图写日记草稿
- **购物记录**：计划购买 / 决定未买 / 已购买，自定义分类，价格数量渠道；AI 识别商品照片或订单截图（多件商品一键保存）
- **孕期打卡**：叶酸、钙片、DHA、维生素 D3（可自定义），连续天数、每日提醒；AI 识别药瓶
- **缓解攻略**：18 种孕期不适、99 个方法，药物类醒目标注「需遵医嘱」
- **准爸妈课堂**：0–6 个月新生儿照护 + 产后妈妈，6 章 15 节课

### 安装
下载下方 `mini-you-v0.1.0.apk`，在手机上打开安装（需允许安装外部来源应用），或用 `adb install -r mini-you-v0.1.0.apk`。

- 最低系统：Android 8.0（API 26）
- 安装包内置智谱 GLM-5.3-Flash 的 API Key，可在「设置 → AI 识图」替换为自己的 Key
